# Employee Scheduler (Python + Rust)

Two-language implementation of a weekly employee scheduling app used to explore control flow, data structures, and (optionally) a GUI.

## Languages
- **Python** (CLI)
- **Rust** via `rustup` (CLI)

## Step 1 – Input & Storage
Collect employee names and their per-day shift preferences (`morning`, `afternoon`, `evening`, or `off`). You can also input rankings like `m>a>e`.

### Run (Python)
```bash
cd scheduler-python
python3 main.py
